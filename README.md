Building infrastructure for coding agents. Previously on the deployment team at [Emergent](https://emergent.sh) (YC S24).

### Products

- **[wsp](https://github.com/wsp-labs/wsp)** - Your dev machine, cloned to the cloud for your coding agents. Claude Code and Codex work inside as threads, and agents start agents. [usewsp.com](https://usewsp.com)
  - **[gpui-agent](https://github.com/wsp-labs/gpui-agent)** - Lets coding agents inspect and drive native GPUI apps through a CLI or MCP server. UI snapshots with source locations, clicks, typing, screenshots and recordings
- **[spoo.me](https://github.com/spoo-me/spoo)** - Open-source link management infrastructure, run solo since 2023. 150M+ clicks, 50+ self-hosted forks, on a $20 VPS
  - **[spoo-py](https://github.com/spoo-me/spoo-py)** - Python SDK
  - **[spoo-ts](https://github.com/spoo-me/spoo-ts)** - TypeScript SDK
  - **[spoo-kotlin](https://github.com/spoo-me/spoo-kotlin)** - Kotlin Multiplatform SDK
  - **[spoo-cli](https://github.com/spoo-me/spoo-cli)** - Shorten links and read analytics from the terminal
  - **[spoo-raycast](https://github.com/spoo-me/spoo-raycast)** - Raycast extension
  - **[spoo-android](https://github.com/spoo-me/spoo-android)** - Android app
  - **[qr](https://github.com/spoo-me/qr)** - The QR code service behind every short link
  - **[spoo-rust](https://github.com/spoo-me/spoo-rust)** and **[spooWASDK](https://github.com/spoo-me/spooWASDK)** - Rust SDK and WinUI app, built by the community

- **[wake up babe](https://github.com/wakeupba/be)** - Color a Google Calendar event red and your phone rings before it starts. Pick up to acknowledge or snooze. [wakeupba.be](https://wakeupba.be)
- **[mFix](https://github.com/Zingzy/mFix)** - Windows 11 window management for macOS. Snap Layouts, live window previews, a Dock that behaves like a taskbar, and Explorer shortcuts in Finder

### Everything Else

- **[code-review-agent](https://github.com/Zingzy/code-review-agent)** - Reviews GitHub pull requests with LangGraph, with background analysis through Celery and a FastAPI API for submitting reviews and reading results
- **[hPyT](https://github.com/zingzy/hPyT)** - Windows title bar and frame control from Python, by reverse-engineering DWM across every Windows version since Vista (140+ stars)
- **[Pollinations bot](https://github.com/pollinations/polli-image-bot)** - The official Discord bot for pollinations.ai, built in 2022 and handed to their team in 2025 (1.5K+ servers)
- **[discord-bot-animator](https://github.com/Zingzy/discord-bot-animator)** - A small Node.js tool for setting animated avatars and banners on Discord bots using discord.js
- **[diskbloom](https://github.com/zingzy/diskbloom)** - A pastel treemap TUI that shows what is eating your disk, on Homebrew
- **[qr-grabber](https://github.com/zingzy/qr-grabber)** - Decode any QR code on screen straight to the clipboard
- **[fluent-2048](https://github.com/zingzy/fluent-2048)** - 2048 in the Windows 11 Fluent design language
